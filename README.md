# Unet网络

本仓库用于保存 2D U-Net 网络项目压缩包。

由于 GitHub 普通仓库单个文件不能超过 100 MB，完整的 `unet_2d.zip`（约 1.0 GB）作为 GitHub Release 附件提供，而不是作为普通 Git 文件提交。

## 下载

请前往本仓库的 [Releases](https://github.com/xueh0635-design/Unet-/releases) 页面下载完整压缩包。

## 说明

- 原始压缩包名称：`unet_2d.zip`
- 压缩包完整性已通过 `unzip -tqq` 检查。
- 仓库实际 URL：[xueh0635-design/Unet-](https://github.com/xueh0635-design/Unet-)
